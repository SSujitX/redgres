# Security policy

Do not report a vulnerability in a public issue. Before public launch, configure a monitored private security contact and GitHub private vulnerability reporting, then replace this paragraph with the final contact procedure.

Include the affected version/commit, impact, reproduction steps, and any known mitigation. Do not include real credentials or customer data.

Supported versions will be listed after the first release. Until then, no Redgres release should be treated as production-supported.

The security architecture and threat model are documented in [docs/SECURITY.md](docs/SECURITY.md).
